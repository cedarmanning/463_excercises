Chrome Dino Game

The Chrome Dino Game was released in 2014 by Google. It appears when users lose internet connection in Chrome.

Players control a dinosaur that jumps over obstacles and avoids enemies. It's simple, fun, and addictive.

Untitled Goose Game

The Untitled Goose Game is a delightful physics-based puzzle game. Players control a goose that can interact with various objects in a charming environment.

It's simple, fun, and addictive.

Flappy Bird

The Flappy Bird game was released in 2013 by Dong Nguyen. It appears when users lose internet connection in Chrome.

Players control a bird that flies through pipes and avoids obstacles. It's simple, fun, and addictive.
